# 首页与访问统计

更新：2026-11-04。

## 布局与参考

参考[少数派](https://sspai.com/)的编辑精选与内容导航、[掘金](https://juejin.cn/)的文章摘要信息流、[豆瓣](https://www.douban.com/)的精选内容及兴趣入口，沿用海燕的纸白、松绿和宋体品牌。

- 欢迎框显示北京时间的当天日期、分时问候、公开文章总数和发布过公开文章的账号数。统计不受首页筛选与分页影响；未加载时显示占位符。
- 精选专区显示最近发布的三篇带 `海燕精选` 普通标签的公开作品，可进入全部精选。
- 文字广场默认每行三张卡片，首页最多展示 9 篇；每行按内容最高的卡片统一高度，顶部、底部均对齐，署名与日期置底。内容区适当加宽，增加卡片内外留白和简介行距；横条也保留适当阅读间距，不展示体裁分类。“再读一些”跳转作品书架，不在首页追加分页。首页布局选择独立于书架的展示偏好。
- 主打活动使用最新创建的活动标签，与现有活动数据保持一致，支持直接参与和阅读投稿。当前活动模型没有起止日期，不推断截止时间。
- 随机推荐从全部公开作品中随机抽取三篇；公开文章达到六篇时，换一批排除上一批。未公开作品不会进入推荐。
- 桌面顶部由欢迎栏与海燕精选各占一半、并排等高展示，欢迎栏最小高度 264px，整行随内容自然增高，保留舒适留白。精选以最多三条纵向导读展示，各篇按内容自然排布，作者、类型与日期紧随标题同行展示，简介独占下一行，不拉伸到栏底；空精选使用等高占位。下方为主信息流与发现侧栏。当前版本仅调整桌面版，移动端另行制作。右侧原话题框替换为固定的当期社刊入口，当前指向《盐与糖：海燕文学社2026年刊》（合集 ID 9）；换刊时更新 `Home.vue` 的 `currentIssue`。

## 阅读层级

首页采用 24px 分区标题、20–22px 文章标题、14px 正文摘要、约 12px 的署名、日期和操作入口；精选摘要为 13px。正文和辅助文字统一加深颜色，正文行距约 1.8 倍。侧栏宽度调整为 300px；三列文章卡片、顶部左右两栏和精选同行信息保留。

## 精选权限

Flyway V16 创建 `海燕精选` 标签，不自动将现有文章设为精选。

进入“社务台 → 稿件管理”，通过“加入精选 / 取消精选”设置。后端限制为当前选择编辑部公用身份的非受限社员、管理员、超级管理员。活动部、技术部及普通个人身份无此权限；受限账号不能通过切换编辑部身份获得权限。

作者编辑器隐藏此标签，后端拒绝通过投稿接口新增精选标签，普通保存保留已授予的精选关系，且不占用五个普通标签的额度。撤回的文章不展示在首页，可以从稿件管理取消其精选。

## 页脚统计

刷新时间下方显示“实时在线 X 人 · 累计访问 Y 人”。

- 页面可见时每 30 秒发送一次带 CSRF 校验的心跳，重新切回页面会立即更新。
- 在线人数按最近 90 秒内有心跳的浏览器去重，包含访客和登录用户；离开页面后最多约 90 秒退出在线统计。
- 累计访问人数按有效期一年的第一方浏览器 Cookie 去重，刷新、路由跳转及同浏览器普通多标签页不重复累加。清除 Cookie、换浏览器或换设备会视作新访客，不能等同于实名人数。
- 数据存入 `site_visitors`，重启应用不会清零；自 V16 迁移启用后开始累计，没有补造此前的历史访问数据。
- 只存随机标识的 SHA-256 摘要及首次、最后访问时间，不保存 IP、浏览器指纹或访问路径。Cookie 为 HttpOnly、SameSite=Lax，HTTPS 请求使用 Secure。
- 统计响应禁止缓存；网络失败显示占位符或上次成功结果，并标注“统计暂不可用”。

## 验证

新增后端权限、标签保护、推荐查询及匿名访问统计测试，前端浏览器测试覆盖排序、书架跳转、失败重试、随机换一批、精选操作、空库、统计不可用，以及桌面三列卡片底部对齐、紧凑横条和书架偏好隔离。

构建仍使用项目原有脚本；部署时须同时更新后端 JAR 与前端静态文件，启动由 Flyway 执行 V16。只更新前端会缺少新首页与统计 API。
