# 社务台

统一侧栏导航、面包屑与页面标题。账户与文章各使用独立路由，文章筛选条件写入 URL，支持直接访问、刷新和浏览器返回。手机端导航横向排列，账户与文章表格切换为卡片，管理操作完整展示。

| 页面 | 路由 | 工作内容 |
| --- | --- | --- |
| 工作概览 | `/admin` | 实际数量、工作入口、最近更新文章 |
| 账户管理 | `/admin/accounts` | 个人账户搜索、角色筛选、权限配置 |
| 公用账户 | `/admin/accounts?view=public` | 公用身份与授权名单 |
| 文章管理 / 审核 | `/admin/works` | 非草稿文章分页检索、预览、精选、下架、审核通过与删除 |
| 活动与标签 | `/admin/tags` | 活动与内容标签分区，发布与结束活动，个人管理员可删除活动 |
| 批量导入 | `/admin/import` | 当前身份一次导入最多 20 份文档，逐份显示结果 |
| 站点资料 | `/admin/settings` | 网站名称与介绍 |
| 注册设置 | `/admin/settings?tab=registration` | 注册开关与测试账号 |
| QQ 注册名单 | `/admin/settings?tab=qq` | 分群搜索、资格筛选、分页、批量启用与停用 |

## 权限

管理员可进入账户、文章、活动标签和站点设置。管理员可调整社员和受限社员，只有超级管理员可调整管理员角色和公用身份授权、删除用户。个人管理员与超级管理员均可删除文章和活动。保留现有“至少一位超级管理员”的服务端约束。

所有公用身份均可发布、编辑本身份文章，发布公告，开展和结束活动，审核通过、下架及管理精选。技术部额外维护站点名称和介绍。删除、账号配置、注册与名单配置由操作人的个人等级决定，切换公用身份保持一致。受限个人账号不能借公用身份取得社务能力。完整规则见 [当前权限体系](PERMISSIONS.md)。

## 文章工作流

发布时执行本地内容规则。命中规则的作者可提交当前版本进入社务台人工复核；审核人可查看申请并通过发布或填写原因退回，修改稿件会使旧申请失效。原有人工巡查仍支持推荐精选、下架和审核通过恢复公开。下架前显示确认弹窗；失败保留操作上下文并允许重试。作者可在书桌中修改和重新发布。

新增 `GET /api/admin/works` 与 `GET /api/admin/works/{id}`，允许个人管理员及所有公用身份访问。草稿从列表、统计、管理预览与操作接口排除。列表提供搜索、状态、体裁、精选筛选、排序、分页与全库汇总，不再受旧概览最近 100 篇限制。正文预览复用阅读页的清理和排版组件。审核身份可查看已下架文章中的非公开图片，仍无法访问未关联稿件的他人上传图片。

## 验证

- `npm --prefix frontend run build`：Vue / TypeScript 检查与生产构建。
- `npm --prefix frontend test`：文章内容处理与分享逻辑。
- `npm --prefix frontend run test:e2e -- tests/admin.spec.ts tests/home.spec.ts`：账户权限、公用身份、文章分页检索、正文预览、精选、下架失败与重试、路由权限、站点设置、QQ 名单、标签、导入及手机布局。
- `mvn -f backend/pom.xml verify`：含内容接口访问控制、参数化筛选、分页边界、非公开正文与图片的权限测试。

本地截图输出到 `output/admin-redesign/`，构建包为 `backend/target/haiyan-chuanxin.jar`。V21 增加账号删除标记，保留历史作品归属；未执行任何实际用户或文章删除。
