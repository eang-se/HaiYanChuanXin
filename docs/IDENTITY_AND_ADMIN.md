# 账号身份与后台管理

平台账号分为个人账号和公用身份。个人账号通过账号和密码登录，公用身份不能单独登录。获授权成员登录后，可从身份选择器切换到公用身份，再随时切回个人账号。

## 公用身份

- 海燕文学社官方：官方消息发布；头像使用文学社印章。
- 海燕编辑部：稿件管理、下架和批量上传；默认头像使用编辑部提供的标志。批量导入的 TXT、DOCX 或文字型 PDF 先保存为编辑部草稿，编辑确认后发布。
- 海燕技术部：网站维护；头像使用技术部标志。
- 海燕活动综合：管理活动和征稿标签；头像使用活动综合标志。

四个身份在公开页面显示认证。每个公用身份同时最多由 5 个不同个人账号使用；同一个人使用多个会话只占一个人数名额。退出、切换身份、授权撤销或会话超时后释放名额；无活动会话 30 分钟后可被回收。授权名单可以超过 5 人。

管理员及超级管理员可以在“社务台 → 账户管理 → 公用账户 → 编辑资料”修改昵称和简介，头像可单独上传保存（PNG/JPEG，最大 5 MB）。自定义头像保存在 `data/avatars/`，备份时须与数据库和 `data/images/` 一起保存。

公用身份的操作与真实个人账号关联并记录操作路径；每次请求重新检查授权，撤销后自动回到个人身份。所有公用身份统一具备本身份文章发布与编辑、活动发布与结束、文章审核通过与下架能力；公告由管理员及以上权限创建，技术部另可设置站点名称和介绍。删除、账号权限、管理员等级和公用名单等高级能力完全依据个人等级，不会因切换公用身份而增加或丢失。受限个人账号不能借用公用身份取得这些社务能力。完整权限表见 [当前权限体系](PERMISSIONS.md)。

## 个人账号

个人账号角色包括超级管理员、管理员、社员及受限社员。超级管理员可管理管理员角色和公用身份授权名单；管理员可管理普通及受限社员。受限社员默认关闭投稿、评论、上传、合集和点赞收藏权限，可以在后台单独开放。系统要求保留至少一位超级管理员。

个人和公用账号均使用统一的简介字段，原签名和简介在 V23 迁移时合并；多行内容在作者主页保留换行。超级管理员可在“社务台 → 站点设置 → QQ 注册名单”上传 UTF-8 Markdown 群名单，每行填写 QQ 号、空格和群内名称；可明确勾选替换同名文件。其他管理员可查看及启停现有名单，但不能上传文件。

实际角色与公用身份使用名单以社务台当前配置为准。原有官方账号的合集和编辑部的稿件沿用原账号 ID。测试注册模式的 `12345 / 0000` 机制仍可用于测试，生产使用时应在后台关闭测试模式。

投稿仍采用原有自动审核后发布流程；稿件管理排除私人草稿，提供公开及已下架作品查看、下架和审核通过恢复公开，并不表示已经启用新的人工投稿审核队列。


账号被删除或注销时，释放登录名、QQ 与个人笔名绑定；删除草稿和私有修订，已公开或撤回文章保留文字署名并转为未绑定的下架文章。文章不再关联原账号、原笔名实体或合集。社务台可查看及删除这些文章；重新上架必须先切换公用身份，文章才归当前公用账号，同时保留原文字署名。已绑定的历史图片按文章关联授权，避免共享图片在不同公用身份接手后不可用。

编辑器不会自动保存没有正文文字或图片的稿件；用户仍可手动保存，未保存修改离开前会提示。
