# 樱花 FRP 临时访问

当前状态：准备完成，尚未创建或启动公网隧道。自动审批拦截了创建与启动命令，没有返回具体原因，需用户在本机执行启动。

## 开启

1. 确认樱花 FRP 启动器已登录，平台可在 `http://127.0.0.1:8091/` 打开。
2. 双击项目根目录 `Start-Tunnel.cmd`。使用免费节点“日本1”（ID 72），创建或复用名为 `HaiYanTemp` 的 TCP 隧道，指向 `127.0.0.1:8091`。
3. 等待显示访问地址与验证结果。地址另存于 `.runtime/tunnel-address.txt`，可以发给临时体验者。若提示未验证，请查看 `.runtime/frpc-*.log` 或启动器中的节点状态。

该脚本使用已安装的官方客户端及现有登录密钥，不把密钥写进项目或进程命令行。不修改原有启动器配置、不创建开机自启、不需要更改防火墙或 Java 监听地址。节点不可用时会停止，不会购买节点或套餐。

此方案提供 **HTTP** 临时访问，浏览器到节点之间未加密，不要用它传输正式账号密码或私密稿件。如需正式登录与投稿，应先配置有效域名和 HTTPS。流量消耗计入樱花 FRP 账号额度；电脑与本地 Java 服务需保持运行。

## 关闭

双击 `Stop-Tunnel.cmd`。脚本只停止自己记录且核对过路径和启动时间的 frpc 进程，保留离线隧道条目以便复用，不停止平台或其他隧道。
