# 作品署名与发布账号

作品的 `byline` 保存实际作者署名，允许联合署名，最多 120 字。`author_id` 仍关联上传账号，决定编辑权限、个人书桌、上传图片权限与合集归属。署名文本不授予账号权限，也不建立虚构社员账号。

API 返回 `byline`（填写值）、`displayByline`（展示值）、`authorId` / `authorName` / `authorAvatar`（发布账号）和 `notes`（附注，最多 4000 字）。署名留空时，展示发布账号当前笔名。旧客户端修改文章时若未提供 byline 或 notes，后端保留原值；显式提交空字符串则清空。

阅读页、卡片、条目列表和合集目录展示署名；发布账号名称链接到该账号主页。编辑器可修改署名与附注。书架搜索覆盖署名、标题、正文及发布账号。

2026 年刊的 25 条内容统一由海燕编辑部管理，21 条填入已识别原刊署名，4 条标记“署名待核”。原正文开头的导入提示移至附注，摘要去除重复署名；文章编号、发布状态、合集与顺序保持不变。数据库变更见 V8__work_byline_and_source.sql 与 V9__work_notes.sql。

## 附注与来源

从 V9 起，`notes` 是统一的附注字段，最多 4000 字，支持换行；来源、页码、创作日期、编辑说明和联合署名说明均可放入。阅读页在正文后展示“附注”，编辑页在正文编辑区下方填写。附注不计入正文的字数统计。

迁移把已有 `source_note` 内容复制到 `notes` 并清空旧列。API 暂保留 `sourceNote` 兼容旧客户端；收到旧字段时会合并进附注并避免重复。旧客户端省略 `notes` 时保留已有值，显式传空字符串可清空附注。编辑器与阅读页不再单独展示“来源说明”字段。

这批 25 篇年刊的来源全部归入附注；《微光》的联合署名说明和另外 4 篇的原刊日期、落款从正文迁至附注，保留原文措辞。更改前有独立数据库备份，迁移脚本对原正文做一致性检查。

## 已绑定的笔名

V11 新增 pen_names 与 member_pen_names。作品以 pen_name_id 指向笔名，author_id 继续代表上传账号。displayByline 优先显示绑定笔名，原 byline 保留作旧客户端与未绑定署名的兼容文本。同名笔名可被多个账号绑定用于署名与归集；这不授予其他账号的稿件编辑权。同笔名有多篇公开作品时，阅读页与作品列表的署名可打开笔名主页。详见 COLLECTIONS_AND_PEN_NAMES.md。
