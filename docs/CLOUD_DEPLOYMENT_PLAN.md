# 海燕传信上云方案

调研日期：2026-10-26。面向大学在读维护者、500 名以内文学社成员；不是 500 人同时在线的容量承诺。本文为方案，不包含购买或部署操作。

## 建议

正式平台优先使用中国大陆地域的腾讯云或阿里云，以一台 4 GB 内存 Linux 服务器起步，同时办理域名与备案，之后接入 QQ 登录。学生认证与普通新客优惠都比较，按实际可购买的套餐和续费价选择。

临时演示可以考虑国内云厂商的香港地域；Azure 学生额度更适合作为开发/教学验证环境。境外地域不等于国内网络质量有保证，也不代表 QQ 登录自动免审核。

## 首期规格与架构

- 2 vCPU / 4 GB RAM；若活动提供 4 核 4 GB，可选，不必为核心数另外加价。
- SSD 40 GB 能起步，优选 60–80 GB。设置日志轮转，长期按每年约 5–10 GB 的业务增长预留；该数值来自先前投稿量假设，实际按使用量修正。
- 公网 IPv4，带宽目标 3–5 Mbps；关注峰值带宽与流量包的差别，不把峰值当持续保障。
- 单台服务器运行 Java 服务、MySQL 和反向代理；图片存本机持久目录，数据库及图片每天备份到另一存储位置。第一阶段无需购买托管数据库、Redis、Kubernetes 或负载均衡。
- 前端仍随 JAR 发布，由同域名提供网页和 API；HTTPS 使用可自动续期的域名证书。Java 与 MySQL 不直接暴露公网端口。
- 本地构建 JAR 再上传云端，避免在小内存主机同时运行生产服务和完整构建任务。桌面图形启动器继续管理本地开发环境，线上由 Linux 服务管理器管理。

这是低成本单机方案，存在单机故障窗口。达到持续高并发、磁盘或数据库瓶颈后，再独立图片存储或数据库。

## 预算方法

首年先把 **300–600 元**作为目标总预算，实际金额取决于能买到的 4 GB 套餐。举例：服务器预算 300 元 + 域名预算 80 元 + 独立备份预算 50 元 = 430 元/年。这里是预算分配示例，不是注册商/云厂商报价，未含外部 AI 审核或短信服务。

不把 38 元首年价外推到第二年，不把 300 元学生券同时扣在不兼容的特价商品上。下单前同时取得第二年续费金额；若学生优惠结束，要按普通续费价继续比较。海外美元资源另按实际结算汇率、税费和出口流量计算。

## 备案和 QQ 登录的衔接

大陆正式网站按接入商要求办理备案。以腾讯云为例，大陆包年包月轻量实例须购买至少 3 个月，备案期间剩余有效期至少 1 个月；香港及境外实例不能作为腾讯云大陆备案资源。见[官方备案云资源要求](https://cloud.tencent.cn/document/product/243/18908)。

QQ 登录仍需网站应用、可登记的固定回调域名及应用审核。正常路径为：域名与备案 → HTTPS 网站 → QQ 应用接入；海外网站的国际域名申请是另一套需确认的审核路径，服务器在香港并不自动获得 QQ 接入资格。

若希望先演示后正式上线，可先在境外短期按月部署、使用自己的域名，后续迁到大陆；但要计入迁移工作和额外费用。若不着急，直接选大陆一年期资源并办理备案更省迁移。

## 采购与迁移顺序

1. 完成腾讯云、阿里云学生认证，领取可用权益；只比价，不必提前充值。
2. 比较满足 4 GB 内存、固定公网入口、目标地域的首年和续费报价。优先选与主要成员接近的大陆地域。
3. 确定域名及备案主体。文学社项目应事先约定个人学生账号、域名与数据的后续交接方式。
4. 采购后准备 Linux、Java、数据库与 HTTPS，迁移现有 MySQL 数据及 data/images，使用独立生产配置。
5. 按用户安排验证恢复、注册、投稿、上传、合集和手机访问，再切换正式域名；本次调研不执行这些操作。
