# 本地部署记录

验证日期：2026-10-25（Asia/Shanghai）。

## 运行方式

- 地址：`http://127.0.0.1:8091/`，Vue 静态资源和 Java API 由同一服务提供。
- 双击项目根目录 `Start.cmd` / `Stop.cmd` 启停；修改后停止服务、运行 `Build.cmd`，再启动。
- 初始管理员为 `admin`，随机密码仅保存在受保护的 `.local/admin-account.txt`。注册已开放，测试 QQ 号为 `12345`，验证码为 `0000`；管理员可在独立后台配置中关闭注册或切换模式。
- 默认仅本机访问；没有修改防火墙或添加开机自启。手机实机联调可使用 `tools/Start-Local.ps1 -Lan`，按需配置本地子网入站规则。
- 程序输出与进程记录在 `.runtime/`；数据库为 `haiyan_chuanxin`，图片为 `data/images/`。

## 环境与结构

项目专用 Temurin JDK 21.0.12.1、Node.js 24.22.1、Maven 3.9.16 位于 `.tools/`，安装归档校验过官方哈希。后端使用 Spring Boot 4.1.2、Spring Security、MyBatis Starter 4.1.0、Spring JDBC、Flyway 和 MySQL 8.0.46。前端为 Vue 3.5.44、Vite 8.3.5、TypeScript 5.9.3、Tiptap 与 Lucide 图标。

复用本机 MySQL 服务，单独创建数据库与限库应用用户。凭据位于 `.local/`，ACL 限制当前 Windows 用户访问，Git 忽略且不进入 JAR。RealmMusic 项目与全局工具链配置保持原样。

前端页面按首页/书架、活动、作品详情、作者、写作、个人书桌、登录和社务台拆分；后端业务按认证、稿件与互动、上传解析划分。Flyway V1 保存平台配置，V2 创建业务表，V3 新增合集与有序篇目。后续变更应新增迁移文件。

## 资源预算（500 名以内成员）

这里按小型文学社、日常少量并发投稿估算，尚未进行 500 人同时访问的压力测试。

本次新版启动并完成健康检查后，Java 工作集约 **277 MB**、私有内存约 **366 MB**，可执行 JAR 约 **56 MB**。这是空载采样，不代表文件解析或访问高峰；本机有约 31.2 GB 物理内存，可满足当前本地开发。

| 项目 | 建议或当前设置 |
| --- | --- |
| 本地 / 小规模单机部署 | 2 vCPU、4 GB RAM 起步 |
| Java | 当前初始堆 128 MB、最大堆 768 MB；额外预留线程、原生库与解析内存 |
| MySQL | 应用连接池上限 5；单机整体预留约 1 GB 给数据库，按实际 buffer pool 调整 |
| 文档解析 | 最多 2 个并行解析，文档 20 MB、PDF 100 页、提取文字 10 万字符上限 |
| 系统盘 | 操作系统与 Java/数据库运行环境之外，业务至少预留 20 GB；开发工具与依赖缓存另外预留 5 GB |
| 带宽 | 本机无需公网带宽；将来校内访问优先校园网，外网容量按图片流量和高峰实测 |

假设每年 2,000 篇作品，正文每篇 0.05 MB、压缩后配图合计每篇 1.5 MB：

`2,000 × (0.05 + 1.5) MB ≈ 3.1 GB / 年`

首版导入文档不保留原件。考虑数据库索引、日志、未使用上传图片和余量，按 **5～10 GB / 年** 预留业务增长；备份另外准备至少两份同等量空间。若未来保存原稿，每篇按 2 MB 计，另外增加约 **4 GB / 年**。这是规划假设，应以社团实际投稿量替换。

备份应成套覆盖 MySQL、`data/` 与 `.local/`，其中一份放在独立设备。当前未配置定时备份与过期上传自动清理。
