# 桌面服务器管理

双击桌面“海燕传信后端启动”，点击“服务器与 QQ 名单管理”。原窗口继续负责本机服务的启动、停止、重启、日志和监听地址。关闭窗口不会停止服务。

## 云服务器

填写 SSH 地址、端口、用户名、可选私钥、systemd 服务名和云端名单目录。配置保存在 `.runtime/backend-launcher/cloud-management.json`，不保存密码或私钥内容。状态、日志、启动、停止、重启和自定义命令在独立 PowerShell 窗口中运行；远程 shell 执行所填自定义命令，请确认目标和内容。启停需要服务器授予该用户相应 sudo 权限；终端可能提示输入 SSH 密钥口令或 sudo 密码。

使用 Windows OpenSSH 的 `ssh.exe` 和 `scp.exe`，严格检查已有 `known_hosts`。首次连接前，请在终端执行 `ssh -p 端口 用户名@地址`，通过独立可信渠道核对服务器指纹后再接受；使用非默认私钥时添加 `-i 私钥路径`。连接地址或密钥变更时应先核实。云端操作不会自动部署程序或覆盖数据库。

## 更新 QQ 名单

选择 UTF-8 编码的 `.md` 文件，文件名是群标识（字母、数字、下划线或连字符），每行格式为 `QQ号 名称`。空行、以 `#` 或 `<!--` 开头的行可用于注释。每个文件最多 1 MB，不能提交空名单、无效号码或同号不同名称。选择“更新本地名单”或“上传到云端”，将替换目标环境同名文件、保留原文件备份，不影响其他群。云端 SSH 用户须有目标目录写权限，并确保应用服务用户能读取新文件和目录；生产配置中的 `haiyan.qq-whitelist-dir` 应与界面填写的云端目录一致。云端上传先放临时文件，再备份和替换，失败时终端会显示错误；遗留的 `.upload-*` 文件可在确认后清理。

应用每次请求重新读取名单，更新无需重启。名单确定成员资格和名称；在网站社务台被停用的 QQ 仍需在那里重新启用。已注册账号不会因名单更改而被删除。旧备份包含成员信息，保存在目标名单目录，扩展名不是 `.md`，不会被应用读取；请按实际备份策略保护并清理。
