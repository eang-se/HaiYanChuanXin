# 首页、列表展示与分享

首页从正在征集横幅开始。首次进入首页的未登录访客看到欢迎弹窗；关闭、选择先逛逛、注册、登录或关于后，在当前浏览器写入 haiyan.welcomeDismissed，后续不再自动弹出。已登录用户不弹窗。原有完整介绍和纸张视觉保留在 /about；导航和页脚都有入口。浏览器清理站点数据后可再次看到欢迎。

列表统一使用 haiyan.feedLayout 偏好，沿用原来的存储键；首页、作品书架、发布账号主页、书桌、收藏、合集列表和合集目录共用。合集内的文章链接继续携带 collection 参数，保留前后篇阅读和原刊顺序。编辑合集时的排序操作保留原有管理布局。

公开文章的分享按钮与公开合集的分享合集按钮打开分享卡片弹窗。前端使用 Canvas 生成 1080×1440 PNG，并在本地生成二维码；图片包含站点标识、标题、署名或发布账号、摘要、体裁或篇数。支持保存图片、复制链接及手动调整分享链接。浏览器不支持自动复制时选中链接供手动复制；手机可长按图片保存。

分享链接默认使用当前站点地址。通过本机 localhost/127.0.0.1 使用时，弹窗提示将其改为其他设备可访问的地址；有效修改会作为当前浏览器的分享站点基址保存，后续分享仍自动填入对应文章或合集路径。生成图片与二维码不请求外部图片或二维码服务。

验证：前端类型检查和构建；分享 URL 协议、路由与换行排版共 4 项测试；浏览器实测首次弹窗、关闭后刷新、首页到合集的横条偏好、合集目录带上下篇参数、合集分享 PNG 生成。后续浏览器访问被权限门禁拒绝，个人书桌的视觉检查以及下载、复制按钮的完整浏览器交互验证未完成。
