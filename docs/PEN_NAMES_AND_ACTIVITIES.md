# 署名与活动管理

## 署名选择

编辑器署名区将已有绑定笔名、佚名、已添加的临时署名与“➕”直接平铺为按钮，选中项高亮，空间不足时换行。点击“➕”后填写名字并完成输入：

- 名字尚未被绑定：立即询问是否绑定。选择“是”立即绑定并加入署名选项；选择“否”加入选项并标注“临时”。
- 名字已经被本账号绑定：直接选择该绑定笔名。
- 名字已被他人绑定：直接作为临时署名加入，不弹出绑定询问。

发布和自动保存不再询问是否绑定。绑定接口在加锁后再次检查占用情况，防止查询后被另一账号抢先绑定；遇到这种冲突时，编辑器自动保留为临时署名。新的绑定不能占用他人已绑定的名字。

佚名只表示署名为“佚名”且不关联绑定笔名。发布账号正常展示，文章继续出现在书桌、作者主页、合集及公开作品列表中；所有权和管理权限不变。

“我的书桌”和编辑器通过“管理绑定笔名”弹窗管理笔名，旧的 `/account?tab=pen-names` 链接也会打开弹窗。编辑器内绑定后立即刷新署名按钮，保留正在编辑的正文。公用身份继续使用临时署名。

## 删除活动

社务台活动列表增加“删除活动”。确认弹窗说明操作会删除活动及稿件中的活动标记，保留文章内容；取消不会发送删除请求，失败可重试。服务端仅允许管理员和活动部公用身份操作，普通内容标签不能通过活动删除接口删除。

删除时先锁定活动，再移除 `work_tags` 关联和活动记录，置于同一事务内。历史草稿读取时跳过已经删除的活动 ID，重新保存不会恢复该活动。

## 数据与接口

- V19 新增 `works.byline_mode`，历史作品默认 `LEGACY`；新编辑器使用 `BOUND`、`ANONYMOUS` 或 `TEMPORARY`。
- V20 解除海燕编辑部的全部笔名绑定，保留原作者署名为临时署名；将作品和草稿中的“署名待核”改为“佚名”。同步更新编辑版本，防止旧页面恢复清理前的绑定。发布账号、正文和列表归属保持不变。
- 草稿随正文保留署名方式；正式发布时才更新已有公开文章的署名。
- `GET /api/member/pen-names/availability?name=…` 返回 `AVAILABLE`、`SELF` 或 `OTHER`，不返回其他绑定人的身份。
- `POST /api/member/pen-names` 立即绑定可用名字。
- `DELETE /api/admin/activities/{id}` 删除活动并保留文章。

验证覆盖输入完成后的即时询问、选择是 / 否、他人占用、占用竞态、取消与重试、佚名发布账号与列表展示、书桌入口、删除活动权限和手机端弹窗布局。

## 编辑器与管理弹窗

- 合集新建、简介与公开状态修改、篇目排序统一在“创建与管理合集”弹窗中进行；关闭未保存内容前询问，保存失败可重试。旧的合集编辑链接转到书桌并打开对应弹窗。
- “添加编辑者字段”在原附注末尾添加一行 `本文编辑为：{个人账号昵称}`，重复点击不会重复添加。公用身份使用 `/auth/me` 返回的 `actorPenName`，昵称为空时使用 `actorUsername`，不会将公用账号名填为操作人。
- 正文不再支持折叠块。历史 HTML 与结构化稿件里的折叠标题、正文展开为普通段落，文字和格式保留。
- 图片选择、粘贴和拖入统一自动转为压缩 JPEG，最长边 1600 像素，并按剩余空间调整质量和尺寸。单篇引用的图片总大小最多 5 × 1024 × 1024 字节，包含封面，同一图片重复使用只计一次。删除引用即释放本篇空间。
- 服务端按 `media_files.size_bytes` 校验草稿和发布，超过总量时拒绝保存，避免绕过浏览器校验。`GET /api/member/images/sizes?ids=…` 仅提供当前发布账号所拥有的图片大小，上传返回压缩后的 `sizeBytes`。
- 编辑器界面使用 12 / 14 / 15 像素的提示、表单与分组标题层级，正文保留阅读字号。
