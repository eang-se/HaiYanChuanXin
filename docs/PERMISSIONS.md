# 当前权限体系

适用版本：个人等级与公用身份权限调整（V21）。

## 身份与等级

登录凭据始终属于个人账号。公用账号是经授权后切换的发布身份，不拥有独立登录口令，也不会向操作人授予管理员等级。

- `MEMBER`：普通社员。个人投稿、编辑、文件上传、合集、评论和互动依照个人功能开关开放。
- `RESTRICTED`：受限社员，个人功能默认关闭，可由管理员按需恢复；不能借公用身份取得发布和社务管理权限。
- `ADMIN`：个人管理员。拥有日常社务管理权限，可删除文章与活动，可配置普通社员的角色与功能开关。
- `SUPER_ADMIN`：个人超级管理员。增加删除用户、授予或调整管理员等级、配置公用账号使用名单的权限。

海燕文学社、编辑部、活动部、技术部等所有公用账号使用同一套日常权限。技术部另有站点名称与介绍设置能力。公用身份每次请求均校验个人账号、授权名单及使用会话；授权撤销或会话到期后返回个人身份。

文章编辑始终以当前发布身份的所有权为边界。取得审核权限不会获得他人私有草稿的编辑或预览能力。

## 文章状态与公告

- `DRAFT` 是作者的私人草稿。文章管理列表、概览、统计、详情预览和管理操作均排除草稿；草稿关联的私人图片也不会因审核身份而开放。
- `PUBLISHED` 是通过现有自动检查后公开的文章。管理员和所有公用身份可人工下架。
- `WITHDRAWN` 是作者撤回或人工下架的文章。人工“审核通过”会复核并恢复上次提交的公开版本，不会发布作者尚未提交的私有修订稿。
- “公告”是独立文章类型，保存为 `genre='公告'`，可在体裁筛选中查看。普通个人账号不能通过请求参数或自定义体裁伪造公告类型。

## 删除语义与保护

删除文章会永久移除正文、私有修订、历史版本、篇目关联、评论及收藏记录。先清理历史版本的图片关联，避免外键残留；可被其他稿件复用的上传文件不会被连带删除。

删除用户采用账号删除标记：从账户名单移除，密码登录、快捷登录、密码重置和既有会话均失效，同时撤销公用身份授权、使用租约及已记住的设备。历史作品、署名和审计记录保留。不能删除公用账号、当前个人登录账号，系统至少保留一位有效超级管理员。

所有删除操作有具体对象的确认弹窗，失败后保留对象和错误信息以便重试。前端入口与后端路由分别校验权限；高级权限不会从公用账号数据库中的 `role` 字段推导。

## 实现位置

- `SecurityConfig`：每次请求从个人操作人生成 `ROLE_ADMIN` / `ROLE_SUPER_ADMIN`；当前公用身份只生成 `ROLE_PUBLIC_STAFF`，技术部另加 `ROLE_PUBLIC_TECH`。
- `ManagementAccess`：管理操作的服务端等级检查。
- `AccountPermissions`：个人功能开关、公用身份统一投稿能力、公用稿件删除的附加检查。
- `frontend/src/composables/admin.ts`：与服务端对应的页面入口及操作按钮控制；公用身份不回退读取公用账号本身的管理员等级。
- `V21__account_deletion.sql`：增加删除标记，不删除或更改既有用户数据。
