# 活动与内容标签

投稿设置分为两项，分别保存：

- **参与活动**：从当前开放的征稿活动中选择，可不选，最多 5 个。新稿的活动链接只有在活动仍开放时才会预选。
- **内容标签**：作者自行输入描述文章内容的关键词，按回车、逗号或“添加”提交；可移除后重新填写。每篇最多 5 个，每个最多 30 字，重复名称自动归并。

活动标记显示为“活动 · 名称”，内容标签显示为“#名称”。两者即使同名也拥有独立身份，填写同名内容标签不会参加活动。“海燕精选”保留为编辑部管理的推荐标记，作者不能自行添加。

社务台“活动与标签”分为“征稿活动”和“内容标签”。管理员及活动部身份可创建、结束和重新开放活动；内容标签页展示作者已使用的关键词。结束活动后，不接受新增参与；已关联该活动的历史作品可保留或移除标记。关闭活动后，首页、活动页与投稿可选列表不再推荐该活动。

## 接口与数据

- `GET /api/public/activities`：仅返回开放的活动。
- `GET /api/public/tags`：保留完整标签目录，用于作品检索、管理与历史展示。
- `PUT /api/admin/activities/{id}/availability`：提交 `{ "active": true/false }`，仅管理员及活动部可操作。
- 投稿接口使用 `activityIds: number[]` 与 `contentTags: string[]`。服务器校验活动身份和开放状态，创建或复用内容标签。旧 `tagIds` 请求仍兼容，不能与新字段混用，且同样执行活动有效性和精选权限校验。

V18 迁移新增 `tags.activity_active`，并将生成列 `topic_name` 的唯一键按活动 / 内容划分命名空间。原有标签 ID 和作品关联保持不变，已有活动默认开放。草稿继续存储解析后的标签 ID，读取时回填分类，兼容已有稿件。只修改标签时保留未编辑的旧正文；版本号随保存更新，避免覆盖其他页面的修改。

## 验证

前端类型检查与生产构建；文章、投稿布局、社务台和首页浏览器回归；后端标签规则与活动管理权限测试。迁移已在独立 MySQL 测试表验证原有记录保留、同名隔离和关闭活动，测试表随后清理。
